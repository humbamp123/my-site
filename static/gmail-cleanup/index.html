Gmail Cleanup

Bulk-clear old mail without handing your inbox to anyone

Not connected
  • Stays in your browser. Your mail goes between this tab and Google. There is no server behind this page.
  • Nothing is deleted for good. Mail is moved to Trash or archived, and every run can be undone.
  • Never reads message bodies. Only sender, subject and date are fetched, for the review step.
  • Nothing is remembered. Access lasts about an hour, lives in this tab only, and is revoked when you disconnect.
Step 1 · Connect
First time? Create your own Google client ID (5 minutes, free)
  1. Open the Google Cloud console, create a project, and enable the Gmail API for it.
  2. Set up the OAuth consent screen as External, leave it in Testing, and add your own Gmail address as a test user.
  3. Create an OAuth client ID of type Web application. Under Authorized JavaScript origins add exactly:
  4. Copy the client ID (it ends in .apps.googleusercontent.com) into the box below. You do not need the client secret; never paste it here.

Using your own client ID means only you can sign in through it, and Google shows you exactly what is being requested.

A public identifier, not a password. Saved in this browser only.
